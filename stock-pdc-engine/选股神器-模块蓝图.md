# 选股神器：模块蓝图

本地地址：`http://127.0.0.1:8765`。它是研究辅助工具，不连接券商、不保存交易密钥、不执行任何真实下单。

## 已落地的模块

| 模块 | 责任 | 当前验证方式 |
| --- | --- | --- |
| 本地壳与 Dashboard | Finder 启动、回环地址、Run 浏览、最终研究结论展示 | 启动后访问 `/api/system/status` |
| 状态引擎 | Run、不可变 Attempt、Checkpoint、选择、STALE、Resume、Diff、六份 Attempt 文件审计 | `tests/test_local_pipeline.py` |
| 1–9 Stage Core | Frozen Facts 到 Final Decision 的确定性本地链路 | `tests/test_stage_executor.py` 与真实本地 Run |
| Codex 只读复核 | 为 03/05/06/07/08/09 创建隔离工作区、固定 JSON 契约、作业日志 | `tests/test_codex_jobs.py` |
| 最终研究界面 | 显示候选/观察/排除及主要风险 | Stage 09 已选择时自动显示 |

## 1–9 Stage 的边界

1. **Frozen Facts**：冻结本次 OHLCV、元数据、运行参数与来源哈希；改事实必须新建 Run。
2. **Hawkeye**：只按筛选规则建立候选池。
3. **Round 1 Members**：对候选逐票做第一轮独立成员评分。
4. **R1 Aggregate / Shortlist**：汇总第一轮并截取短名单。
5. **Round 2 Members**：只对短名单重新评分。
6. **Secretary**：整理分歧、均值、状态和风险摘要。
7. **Blue Whale**：在冻结证据上做独立研究风险复核。
8. **Final Gate**：把标的分至可研究、观察或阻断。
9. **Final Decision**：输出 `RESEARCH_CANDIDATE`、`WATCH`、`EXCLUDED`；不会输出真实下单动作。

每个 Stage 写入：`input.json`、`config.json`、`output.json`、`validation.json`、`checkpoint.json`、`audit.json`。只有人工选择有效 Attempt 才会解锁下游；若重新选择上游版本，所有已选择的下游自动变为 `STALE`。

Dashboard 的「逐 Stage 文件审计」不做摘要替换：用户可以选择任意已生成的 Stage / Attempt，逐个读取这六份完整 JSON，并对照文件大小和 SHA256；接口仅允许这些固定文件名，不能借此读取项目中的任意路径。

## Codex 边界

- 只能由页面的「使用 Codex 复核（只读）」明确启动，绝不自动运行。
- 工作目录位于 `runs/<run-id>/codex-jobs/<job-id>/workspace/`，只写入已选择的上游输出、固定任务描述和 JSON Schema。
- 固定使用 `codex exec -s read-only`；页面无法传入命令、路径、模型参数或自定义提示词。
- 结果仅作为独立审计证据，绝不会自动选择、覆盖或修改任何 PDC Checkpoint。

## 每次修改一个模块的验收顺序

1. 修改对应模块与其单元测试。
2. 跑该模块测试，再跑 `python3 -m unittest discover -s tests -v`。
3. 如涉及页面，运行 JavaScript 语法检查并启动仅回环的本地服务检查接口。
4. 如涉及 Stage 语义，先用临时数据全流程验证，再按需用真实本地数据生成一个新的 Run。
5. 检查 `git diff --check`，并确认 `liveTrading` 始终为 `false`。

## 启动

在 Finder 双击 `选股神器.app`，或双击 `选股神器.command`。命令行备用入口为：

```bash
python3 scripts/start_pdc_local.py
```

更完整的接口、CLI 与文件约定见 [LOCAL_PDC.md](LOCAL_PDC.md)。
