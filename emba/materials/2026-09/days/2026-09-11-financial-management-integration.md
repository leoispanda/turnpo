## 第一部分｜今天讲什么

### 生活故事｜《通过率最高的驾校》

小林准备学开车。

她在网上搜索附近的驾校，第一家广告写着：

> 首次考试通过率92%，连续三年本地区第一。

广告下面放着十几张照片。照片里的学员站在考试中心门口，手里拿着刚刚取得的驾照。很多评论也提到，这家驾校要求严格，但很会帮助学员准备考试。

小林很快作出决定。

“就选这家吧。通过率最高，应该最可靠。”

她的同事安娜刚好也在学车，听完后问：

“你知道这个通过率是怎么算的吗？”

小林摇了摇头。

“通过的人除以参加考试的人，不就是通过率吗？”

安娜重新打开驾校的网站。

页面最上方写着92%，但在很下面的位置还有一行小字：

> 数据仅包括完成全部课程，并由教练安排参加首次考试的学员。

“这有什么问题？”小林问。

“可能没有问题。”安娜说，“但没有完成课程的人不在里面，教练认为还没有准备好、不允许报名考试的人也不在里面。”

小林打电话询问驾校。

接电话的人很坦率地告诉她，这家驾校对考试报名控制得非常严格。学员只有通过内部模拟测试，教练才会帮助预约正式考试。

“这样不是挺好吗？”小林说，“至少不会让学员没有准备好就去考试。”

“当然有好处。”安娜回答，“但这也意味着，92%并不代表所有报名学员的成功率。它代表的是被教练选中参加首次考试的人当中，有92%通过。”

第二天，小林又查看了另外两家驾校。

第二家的首次考试通过率只有68%。但这家驾校接受很多以前在其他地方学过、已经多次考试失败的学员，也允许学员自己决定什么时候参加考试。

第三家没有公布一个统一的通过率，而是分别列出了：

- 手动挡学员通过率；
- 自动挡学员通过率；
- 首次考试通过率；
- 补考通过率；
- 普通课程完成情况；
- 强化课程完成情况。

单看最大的数字，第三家并不突出。

但是，小林至少能够知道，这些数字是在什么条件下产生的。

她开始继续比较价格。

通过率92%的驾校，基础套餐看起来并不贵，包括二十节课和一次模拟考试。不过，很多学员最后还需要额外购买十到十五节课程。周末和晚上上课需要另外收费，考试当天使用教练车辆也不包含在套餐中。

通过率68%的驾校，每节课稍贵，却没有另外收取周末费用，重新安排课程也比较灵活。

如果只比较广告上的套餐价格，第一家明显更便宜。

但是，把学员实际可能使用的课程、考试车辆和额外费用全部算进去以后，两家的差距就没有那么大了。

小林还发现，这些驾校服务的学员并不完全相同。

第一家主要提供密集课程。学员每周至少上三次课，通常希望在两三个月内参加考试。这种安排很适合时间比较自由、能够集中练习的人。

小林刚开始一份新工作，每周只能在周末上一节课。她学习速度不慢，但在复杂路口容易紧张，需要较长时间建立信心。

安娜说：

“通过率最高的驾校可能确实很好，但它的课程不一定适合你的时间和学习方式。”

小林仍然没有完全放弃第一家，于是预约了一节体验课。

教练技术很好，讲解也很准确。但整节课安排得非常紧。小林刚完成一个动作，教练便要求她立刻进入下一个练习。

课程结束后，教练建议她购买三十节强化课程，并尽量在工作日安排训练。

“如果我只能每周上一节课呢？”小林问。

“进度会比较慢。”教练说，“而且我们不能保证给你固定的周末时段。现在学员很多，每位教练每天的课程都排得很满。”

小林这时才明白，过去的高通过率是在一套特定条件下形成的：

- 教练严格控制谁可以参加考试；
- 学员需要保持较高的训练频率；
- 课程安排比较紧凑；
- 大部分学员能够配合驾校的时间；
- 统计只包括已经完成课程并正式参加首次考试的人。

这些条件本身没有问题。

问题只是，它们和小林的情况并不完全匹配。

最后，小林选择了第三家驾校。

这家驾校的广告没有写“本地区第一”，教练也没有承诺她一定能在多少节课以后通过考试。

体验课结束后，教练只是清楚地告诉她：

“按照你现在的情况，可以先每周上一节。等你对道路判断更加稳定以后，再决定是否增加训练频率。现在还不能准确预测你需要多少节课。”

半年后，小林参加了第一次考试，但没有通过。

她在一个繁忙路口判断得太慢，考官进行了干预。

小林当然很失望。

教练没有急着为她预约下一次考试，而是把考试报告和过去几个月的训练记录放在一起，找出她在复杂路况中的共同问题。

六周后，小林第二次参加考试，顺利通过。

拿到驾照那天，她没有出现在“首次考试通过”的宣传照片里。

但她并不觉得自己选择了更差的驾校。

她选择的是一个能够诚实说明条件、费用和不确定性，也适合自己学习节奏的驾校。

后来，另一位同事问她：

“哪家驾校最好？”

小林没有直接说出名字。

她先问：

“你以前开过车吗？想学手动挡还是自动挡？每周能上几次课？你是想尽快考试，还是更在意慢慢建立信心？”

同事笑了。

“我只是问哪家通过率最高。”

小林回答：

“通过率当然要看。但你还要知道，是谁参加了考试，谁没有参加，花了多少钱，以及他们是不是和你一样的学员。”

### 今天真正要学会的判断

Historical return 是已经发生的结果，但它不是 manager skill 的直接证明。

就像驾校的高通过率可能受到学员基础、考试筛选、课程强度和统计方式影响，一只基金过去表现较好，也可能来自：

- 更有利的市场环境；
- 更高的风险暴露；
- 特定的投资风格；
- 汇率变化；
- 较高集中度；
- 样本选择；
- 或真正的 manager skill。

因此，今天的任务不是根据历史排名直接选出冠军，而是先完成以下判断：

1. 比较对象是否真正可比；
2. 样本是否完整；
3. 回报是否经过风险和费用调整；
4. 差异是否来自结构、市场或经理能力；
5. 产品是否适合具体投资者。

只有完成这些判断，历史表现才能被转化为专业建议。

### 五步知识链｜从“最高通过率”走到专业建议

> 先确定谁会根据比较作决定 → 再检查哪些样本没有进入结果 → 再统一比较对象和计算口径 → 再解释扣除成本与风险后的差异 → 最后判断产品适合谁

看到一家驾校宣传“首次考试通过率全区第一”时，人会自然地认为它就是最好的选择。

但在作出判断以前，还要先问：

- 哪些学员进入了统计；
- 哪些人没有参加考试；
- 不同驾校接收的学员是否相似；
- 价格是否包含实际需要的全部费用；
- 这种课程安排是否适合具体学习者。

基金比较也是如此。

看到一只基金过去三年排名第一时，“能买吗”不应该是第一个问题。

先学会检查样本、比较口径、风险、费用和投资者需求，才有资格把历史结果转化为专业建议。

---

#### 01｜先确定这场比较是替谁作的，不让“最好”脱离使用者

一只基金不会脱离投资者而自动成为最好。

对一位五年内要使用资金、不能承受大幅波动的人，和对一位持有期很长、能够承担权益风险的人，同样的历史回报意味着不同选择。

因此，我们先把使用者放进判断中：

- investment objective；
- holding period；
- investor currency；
- liquidity need；
- risk tolerance；
- 实际能够购买的产品范围；
- 税务或其他现实限制。

随后才统一比较对象：

- 基金属于什么 asset class；
- 是否属于同一个 fund category；
- 是否为相同 share class；
- 是 active 还是 passive；
- 投资地区和策略是否相近。

这个动作看起来基础，却决定后面所有数字能否比较。

若 decision set 本身不同，“哪只最好”就不是一个有意义的结论，而只是把基金名称和回报数字放在了一起。

---

#### 02｜比较平均表现以前，先检查哪些样本没有被看见

接下来，要先怀疑历史记录是否只留下了表现较好并且继续存在的基金。

表现不佳的基金可能被：

- 关闭；
- 合并；
- 改名；
- 停止销售；
- 从数据库中移除。

如果这些基金不再出现在历史数据中，剩余基金的平均表现自然会显得更好。

这就是 survivorship bias。

它和驾校通过率的问题相似：

不是留下来的数据一定是假的，而是没有完成课程、没有参加考试或已经离开的学员，可能根本没有进入最终数字。

因此，在计算任何回报以前，需要先检查：

- 样本来自哪里；
- 哪些基金被纳入；
- 哪些基金被排除；
- 已经关闭或合并的基金是否仍然保留；
- 是否存在 backfill；
- 基金的起始时间是否一致；
- 选择的期间是否避开了困难年份。

这个步骤不是为了否定所有数据，而是为了理解：

> 样本规则正在怎样影响最后的结论。

先修复比较的地基，后面的统计才有意义。

---

#### 03｜样本站稳后，再把不同回报放到同一把风险尺子上

样本相对可靠以后，才开始比较 return。

更高回报可能来自更好的经理能力，也可能来自：

- 更高的 equity exposure；
- 更高的 interest-rate risk；
- 特定的地域配置；
- 不同的 investment style；
- factor exposure；
- currency exposure；
- concentration；
- liquidity risk。

在没有调整以前，这些来源在历史回报中可能看起来完全相同。

因此，benchmark 不能随意选择一个市场指数，而要尽量匹配基金的：

- asset class；
- geographical scope；
- investment style；
- factor exposure；
- investable universe。

比较期间也必须公平。

只看某一类资产表现特别好的年份，容易把有利环境误认为能力。

跨币种比较时，还必须说明使用：

- local currency；
- investor currency；
- 还是 hedged return。

Raw return 并不是没有价值，但它还没有完成解释。

把 benchmark、period、currency 和 risk exposure 统一以后，才可能判断我们究竟在比较：

- 经理能力；
- 市场环境；
- 风格暴露；
- 还是汇率影响。

---

#### 04｜再看投资者真正拿到的净结果，并拆开差异来源

即使两只基金承担了相近风险，投资者最终得到的结果仍然可能不同。

需要考虑的成本包括：

- expense ratio；
- sales load；
- transaction cost；
- tax；
- liquidity cost；
- portfolio turnover。

同时，还要观察为了获得这些回报承担了什么：

- volatility；
- drawdown；
- concentration；
- liquidity risk；
- capacity constraint。

这就像驾校的广告套餐价格，并不一定等于学员实际支付的全部成本。

只有把额外课程、考试车辆、晚间费用和其他支出放回去，才能看到真实结果。

基金也一样。

一项策略在基金规模较小时可能有效。基金资产快速扩大以后，原有投资机会可能不足以容纳全部资金，交易成本也可能上升。

因此，过去的小规模成功，不一定能够按同样比例继续复制。

Otten and Schweitzer 的行业比较还提供了 Structure–Conduct–Performance 的视角。

以下结构条件可能影响费用、产品设计、竞争方式和投资者行为：

- 基金数量；
- 平均基金规模；
- distribution channel；
- pension system；
- 家庭投资习惯；
- 监管和市场制度。

这个框架帮助我们提出更好的解释，但不能把相关关系直接写成因果关系。

分析的目的不是制造一个更复杂的冠军故事，而是逐步拆解：

> 回报差异中，有多少来自 exposure，有多少来自 cost 和行业结构，还有多少可以谨慎地归因于 manager skill。

---

#### 05｜最后才把分析翻译成对具体投资者有边界的建议

现在才回到最初的问题：

> 这只基金能买吗？

好的 recommendation 不是宣布一个永久赢家，而是说明：

- 产品为什么适合这位投资者；
- 哪些证据最支持这个判断；
- 投资者需要承担哪些风险；
- 哪些 assumptions 尚未验证；
- 数据和方法存在哪些 limitations；
- 哪些变化会触发重新评估。

这就是 suitability。

同一只历史冠军，可以适合：

- 风险承受能力较高；
- 投资期限较长；
- 能够接受较大波动的投资者。

但它可能不适合：

- 五年内需要使用资金；
- 依赖稳定现金流；
- 无法承受较大 drawdown；
- 或者投资范围受限制的客户。

证据不足时，限制结论并不是分析能力不足，而是专业判断的一部分。

最终推荐的不是一个孤立的基金名称，而是一段匹配关系：

> 产品的风险、回报和限制，与投资者目标、期限和承受能力之间的匹配。

### 故事对应｜从通过率到专业判断

| 驾校故事中的情节 | 今天的投资判断 |
|---|---|
| “首次考试通过率92%” | Historical performance 是比较起点，不是能力的直接证明 |
| 只有完成课程并获准考试的人进入统计 | Sample selection 与 survivorship bias |
| 退出、转校或未参加考试的人没有被看见 | Sample integrity |
| 首考、补考、手动挡和自动挡分别统计 | Benchmark 与 category 必须统一 |
| 不同驾校接收的学员基础不同 | Initial conditions 与 risk exposure 不同 |
| 广告套餐之外还有额外课程和车辆费用 | Fees 与 net result |
| 密集课程提高通过率，但不适合所有学员 | Return 背后的投入、风险和约束 |
| 学员增加后，固定时段和教练资源不足 | Size 与 capacity constraint |
| 小林按照时间和学习方式选择驾校 | Suitability |
| 推荐前先了解对方的基础、目标和时间 | Professional recommendation |

### 类比边界

驾校通过率能够帮助理解：

- sample selection；
- comparison basis；
- hidden cost；
- capacity；
- suitability。

但是，基金表现比驾考结果更加复杂。

真实基金还涉及：

- asset correlation；
- market exposure；
- factor model；
- portfolio construction；
- currency；
- tax；
- trading restrictions；
- investor behaviour。

驾校中的“学员基础不同”，只能帮助理解比较条件不同，不能完全代表金融中的 risk exposure。

同样，高通过率不等于教练能力，高 risk-adjusted return 也不会自动证明 manager skill。

Risk-adjusted metric 只能帮助我们提出更好的问题，不能单独证明未来表现。

Structure–Conduct–Performance 也不是单向因果模型。行业结构可能影响基金行为，基金行为也可能反过来改变行业结构。

正式结论仍然需要：

- transparent data；
- appropriate benchmark；
- clear methodology；
- 明确的 assumptions；
- 以及诚实的 limitations。

---

### 应用到自己的公司｜完成一张公平比较卡

选择公司内部的一项“冠军排名”，例如：

- 最佳销售团队；
- 最高绩效员工；
- 最成功市场活动；
- 最低成本仓库；
- 最高转化率渠道；
- 最快完成的项目。

只回答五个问题：

#### Decision user

谁会根据这个排名作出什么决定？

#### Sample

哪些失败、停止、退出、合并或没有完成的样本没有被看见？

#### Benchmark

不同对象的起点、资源、市场、风险和期间是否一致？

#### Net result

扣除成本、资源、规模和现实约束以后，差异还剩多少？

#### Recommendation

这个冠军适合什么场景？哪些条件变化会改变建议？

5. **Historical boundary**：哪些 2002 年的事实不能直接外推到 2026 年？

#### 内容概述

文章比较欧洲与美国 mutual fund industry 的规模、结构、费用、销售与表现背景。欧洲市场在当时更碎片化、基金数量多而平均规模较小；美国市场更成熟、规模较大，并受到养老金与直接投资渠道影响。这些差异可能关联规模经济和费用，但不能脱离制度环境做简单优劣判断。

最需要迁移的不是旧数据，而是作者的比较意识：先说明市场结构，再解释参与者行为，最后谨慎评价表现。今天使用文章时，必须把历史事实与可迁移方法分开，并用更新数据才能回答当代行业问题。
