## 第一部分｜今天讲什么

### 知识寓言｜《第三勺红油》

南城老街有一家川菜馆，叫“灯影楼”。店面不大，门口挂着一串旧灯笼。每天傍晚，厨房里的第一声铁锅响起，整条街就开始有了香气。花椒被热油一激，麻味先出来；干辣椒在锅边一翻，香味才慢慢沉下去。熟客说，灯影楼的菜好，不是因为最辣，而是因为它知道什么时候该辣，什么时候该收。

老板娘林姨最看重一道菜：水煮牛肉。她说，这道菜看起来简单，其实最难。牛肉要嫩，汤底要厚，红油要亮，最后那一勺热油要浇得准。早一秒，香味起不来；晚一秒，辣椒就苦了。

后来，老街变成了旅游街。新餐馆越开越多，租金也一年比一年高。林姨请来一位新店长，叫周明。周明很能干。他看了三天账本，说：“灯影楼不能只靠老师傅的手感，要靠清楚的管理。”

他做了一张评分表。每道菜都要记录：出菜速度、食材成本、毛利、顾客评分和退菜次数。每周一，前厅和后厨一起看表。红色数字要解释，绿色数字有奖励。刚开始，效果很好。上菜快了，浪费少了，毛利高了，客人点评也多了。那张表贴在办公室墙上，像一面刚擦亮的铜镜。

可是，厨房的味道慢慢变了。

为了提高出菜速度，师傅提前把一部分菜炒到半熟；为了降低成本，牛肉片切得更薄；为了减少退菜，辣度被调得越来越温和；为了获得更高评分，服务员更愿意推荐拍照好看的菜，而不是那些费工夫、但真正能留住老客人的菜。

表上的数字都很好看。

但林姨发现，水煮牛肉端上桌时，红油还是红的，香气却短了一截。熟客吃完不再说“今天这锅有劲”，只是客气地点点头。最奇怪的是，厨房里越来越安静。以前老师傅会听锅声、看油色、闻花椒香；现在大家一边炒菜，一边看墙上的出菜时间。

店里有个年轻厨师，叫阿远。他一直想做一道新菜：青花椒藤椒鱼。这道菜不用传统重油重辣，而是用青花椒的清麻和鲜鱼的嫩味。他试了很多次。第一次鱼肉散了，第二次汤底太薄，第三次麻味太冲，第四次客人说“不像川菜”，第五次终于有一点清亮的回味，但出菜时间还是太长。

周明把这道菜放进评分表。结果很难看：成本高，速度慢，评分不稳定，毛利也不突出。“这道菜应该停掉。”周明说，“它拖了后厨的效率。”

阿远没有反驳。他只是把几次失败的记录拿出来：哪一种鱼容易碎，哪一种青花椒香气更长，哪种火候能让鱼片不老，哪类客人愿意接受不那么油重的川味。他说，这道菜还没有成功，但每一次失败都让厨房知道了一件以前不知道的事。

林姨看了很久，忽然问周明：“如果我年轻时第一次做水煮牛肉，就用这张表来评，我可能早就不做这道菜了。”

周明没有说话。

第二天，林姨没有撕掉评分表。她知道，没有数字，餐馆迟早会被成本、浪费和混乱拖垮。老师傅的手感重要，但手感不能成为不算账的理由。

她只是在旁边挂了第二张表。

第一张表继续管成熟菜：水煮牛肉、宫保鸡丁、回锅肉、麻婆豆腐。这些菜已经有稳定做法，就要看出菜速度、成本、质量和顾客反馈。成熟的菜不能每天都说“今天情况特殊”。

第二张表只管新菜。它不问这周赚了多少钱，而问三个问题：这次试验验证了什么？排除了什么？下一次要改变什么？阿远的藤椒鱼不再占用晚高峰灶台，只能在下午试菜；每次只拿一小笔预算；每过一关，才能进入下一步。

后来，周明又遇到一件事。店里最赚钱的一道新菜，是“火焰辣子鸡”。上桌时服务员会点火，手机一拍，非常好看。游客喜欢，评分很高，毛利也高。按第一张表，它应该放到菜单首页。

但林姨没有同意。

她指着门口旧灯笼下的一行字：“让离家的人，吃到一口有根的味道。”

她说：“我们可以做游客喜欢的菜，也可以赚钱。但如果一道菜只有热闹，没有味道；如果它让厨房为了表演牺牲火候；如果它把真正的川味变成一场短视频，那它分数再高，也不能代表灯影楼。”

从那以后，灯影楼多了三条不能绕过的规矩：食材不能不新鲜，火候不能只为速度让路，招牌味道不能为了讨好所有人而失去根。任何人想破例，都必须写清楚理由、负责人和什么时候回看结果。

几年后，老街上的餐馆换了一批又一批。有的店菜单更厚，有的店装修更亮，有的店评分更高。但很多人还是愿意走进灯影楼。

他们说，那家店最好的地方，不是只相信老师傅，也不是只相信表格。

它真正守住的是第三勺红油。

第一勺红油，让菜有颜色；第二勺红油，让香味出来；第三勺红油，决定这道菜有没有魂。

管理也是这样。数字让人不糊涂，控制让人不跑偏，但真正好的控制，不是把所有菜都炒成同一个味道，而是知道什么该稳定，什么该试，什么分数再高也不能越过那口真正的味道。

### 今天真正要学会的判断

Management accounting 提供成本、预算和绩效信息；management control 决定这些信息怎样影响注意力、资源和行为。今天不是学习“更多 KPI”，而是学习：**什么信息适合当前决定，它会诱导什么行为，以及不确定性变化时控制应怎样改变。**

### 五步知识链｜我怎样带你把战略意图变成不伤人的控制

> **先弄清要作什么决定 → 再挑真正有用的信息 → 再预演指标会怎样改变行为 → 再按不确定性选择控制方式 → 最后让价值取舍进入资源决定**

管理控制的误区，是以为一张更精细的 KPI 表就能带来更好的管理。我们今天换一个起点：控制不是表格，而是一套让人注意什么、怎样分配资源、在什么情况下停下来的安排。下面五步，就是从战略意图走到这套安排的过程。

#### 01｜先把要作的决定说清楚，控制才知道自己该服务谁

先不要急着列 KPI。管理者此刻是在为成熟产品定价、压缩成本、在几个项目之间分配资源，还是在探索一个尚未验证的新机会？这些决定表面上都需要“数据”，但需要的数据、时间范围和允许的失误完全不同。

因此第一步是把场景讲清：战略目标是什么，谁是 decision owner，决定必须在多长时间内作出，希望团队因而采取什么行动。Controller 或 business partner 的价值也在这里——不是递上更多报表，而是帮助业务把模糊的“我们要提升表现”拆成一个可被支持的真实决定。控制从定义问题开始，而不是从选择指标开始。

#### 02｜有了决定，再挑那些会改变选择的信息，而不是挑最容易算的数字

现在才进入 management accounting。信息是否有用，不在于它多精确，而在于它会不会改变这次选择。比较两个方案时，要分清哪些成本会随着方案改变，哪些已经承诺、无论怎样都不会消失；也要看容量、客户价值、时间范围和数据口径是否真的相关。

这会让你明白，decision support 和 performance evaluation 不能混用。一项用于帮助管理者比较方案的成本数字，未必适合拿来考核员工；一项方便统计的指标，若不能推动更好的选择，就只是 false precision。控制的第二层纪律，就是敢于把看似专业、却与决定无关的数据留在表外。

#### 03｜指标一旦影响奖励，就先预演人们会怎样聪明地追逐它

当一个指标被连到奖金、晋升、预算或排名，它就不再只是测量工具，而会成为行为规则。于是我们要比“它能不能衡量”多走一步：假如所有人都认真把它做高，组织真正想要的结果会不会反而变差？工匠会不会为了成本分数缩小钟面，为了准时率把复杂客户排除在外，为了利润把必要的维护推迟？

这不是对员工的不信任，而是对激励机制的尊重。好的控制设计会检查 controllability、gaming、短期主义、重复计量和未被衡量却很重要的后果。Strategic ranking 仍然有价值，因为它迫使不同项目用相近语言比较；但分数应该帮助讨论，而不是自动取代判断。

#### 04｜再看环境是否稳定：成熟业务用纠偏，探索业务用学习

接下来要承认一件事：并非所有活动都适合同一种控制。因果关系已经清楚、执行方法比较稳定的成熟业务，适合 **diagnostic control**：设目标、看偏差、纠正执行。这里过多讨论反而会拖慢运营。

但面对新技术、新客户或新商业模式，组织还不知道什么会成功。此时把同一套年度预算和当期利润目标压上去，往往会过早杀死有价值的探索。更合适的是 **interactive control**：小额分阶段投入、设技术或客户里程碑、反复测试关键假设。失败只有在它留下可以迁移的证据、并改变下一步 continue、expand、pivot 或 stop 的选择时，才叫 valuable learning。

#### 05｜最后让 purpose 和管理判断真正进入预算、门槛与例外记录

到最后，数字与战略意义难免冲突。一个项目可能分数最高，却伤害客户体验；一个创新试验短期亏损，却在学习关键能力。这里不能简单说“相信直觉”，也不能让排名机械地替公司作决定。先把不能被交换的 minimum gates 说清，例如 safety、ethics、合规或核心 customer value；过不了门槛的项目，分数再高也不能继续。

在门槛之上，管理者可以作出有证据的例外判断，但必须留下理由、owner、复盘时间和事后结果。这样 purpose 才不是墙上的口号，而会进入预算、资源分配和后果；management judgment 也不是任性，而是可以被回看、被挑战、被学习的责任。

### 寓言对应｜只记住五个动作

| 故事动作 | 今天的控制判断 |
|---|---|
| 每道菜都进入评分表 | comparability 与 management accounting information |
| 厨房为了速度、成本和评分改变做法 | KPI gaming 与 behavioural consequence |
| 藤椒鱼多次失败但留下试验知识 | innovation learning 与 option value |

| “有根的味道”成为不能绕过的门槛 | purpose、minimum gate 与 accountable judgment |

### 类比边界

川菜的味道可以现场尝，真实组织的战略价值、创新潜力和 purpose alignment 更难观察。Interactive control 不是增加会议，qualitative judgment 也不是反对数字；控制设计仍要考虑业务模式、失败成本、数据质量和人的可控程度。

### 应用到自己的公司｜完成一张控制设计卡

选择一个影响奖金、资源或晋升的指标，只写五行：

1. **Decision**：它试图支持什么决定？
2. **Information**：它真正衡量了什么，遗漏了什么？
3. **Behaviour**：所有人追逐它时，可能出现什么副作用？
4. **Uncertainty**：这里需要 diagnostic control 还是 interactive learning？
5. **Judgment rule**：什么门槛不能绕过，什么例外可以有证据地批准？

Tennessee Controls 提醒你模型会提高一致性，也会制造盲点；Davila 说明控制能够为创新建立学习纪律，而不必只做结果监督；Quinn & Thakor 则把注意力带到数字之外，检查组织的 purpose 是否在真实资源和后果中兑现。三项阅读共同说明：**好的控制不是让人服从更多数字，而是让正确的信息、行为和学习服务于战略。**

## 今日 Assignment｜Tennessee Controls：从“单一评分”写到可治理的决策系统

这题不是复述案例。你的任务是说明怎样让 formal asset-acquisition process 保留可比性，同时不让一个 numerical score 取代战略判断。

### 两段回答骨架

**1. Strategic Control Model 怎样改善决策**

把 Strategic Ranking Index 放进完整循环：战略假设与优先级 → 项目证据与比较 → 资源配置 → 实施反馈 → 战略复核。指出它应暴露假设、不确定性与项目之间的互补／冲突，而非自动决定投资。

**2. Simons' Levers of Control 怎样补强 diagnostic control**

| 控制杠杆 | 应写出的作用 |
| --- | --- |
| Diagnostic system | 保留 ranking、预算纪律与计划偏差追踪。 |
| Belief system | 让经理知道公司追求什么战略价值，而不只追逐分数。 |
| Boundary system | 设定 ethics、safety、compliance、capital-at-risk 与 strategic-fit 等不可跨越门槛。 |
| Interactive control | 围绕重大不确定性进行高层持续讨论，用新证据决定 continue、stage、pivot 或 stop。 |
