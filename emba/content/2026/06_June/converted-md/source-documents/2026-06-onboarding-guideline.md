# MaastrichtMBA Onboarding Guideline - Access Setup

## 1. One-Line Summary

This file is the practical "make the MBA runnable" checklist: password, MFA, Canvas, UM email, Teams, and notifications.

## 2. Source Role

This PDF is part of June 2026 because it is preparation infrastructure, not classroom content. It tells the student how to become reachable and ready before the July introduction and later modules.

## 3. Setup Flow

The document follows this dependency chain:

1. Confirm that the UM password, student I-number, and UM student email are available.
2. Set or recover the UM password.
3. Install and configure Microsoft Authenticator for MFA.
4. Log into Canvas.
5. Log into UM email.
6. Connect to Microsoft Teams.
7. Turn on channel notifications.

The practical insight is that MFA is the gate. If MFA is not working, Canvas, UM email, and Teams access may fail or become unreliable.

## 4. Access Components

| Component | Why It Matters |
| --- | --- |
| UM password | Needed for Canvas and UM email login. |
| Student I-number | Used as the username in several login flows. |
| Microsoft Authenticator | Required extra security layer for university systems. |
| Canvas | Course preparation, documents, materials, modules, assignments, and grades. |
| UM email | Official university communication channel. |
| Teams | Programme-wide announcements, documents, elective registrations, events, and group chats. |

## 5. Teams Notification Rule

The most operationally important instruction is to enable Teams notifications channel by channel.

Channels to prioritize:

- General;
- Electives;
- On-campus;
- Online only if relevant for a specific track or group.

For the on-campus EMBA path, the key active channels are General, Electives, and On-campus.

## 6. Work Application

Treat onboarding as an operating-system setup, not an admin chore. Before any course week:

- log into Canvas and check the dashboard;
- check UM email regularly;
- confirm Teams access on desktop and mobile;
- verify notifications before registration or elective deadlines;
- keep this checklist in the June preparation folder.

## 7. Risks

| Risk | Why It Matters | Prevention |
| --- | --- | --- |
| MFA not configured | Blocks access to core systems | Set up Microsoft Authenticator first. |
| Canvas not checked before class | Missed preparation material or assignments | Browse Canvas before each module. |
| UM email ignored | Official messages may be missed | Add recurring email checks. |
| Teams notifications off | Registration and programme updates can be missed | Enable notifications for each channel separately. |
