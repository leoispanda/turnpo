# IMG 6910 - Storytelling And Presentation Practice

## Source

- Original image: `/emba/materials/2026-07/handwritten-notes/images/IMG_6910.jpeg`
- Overall Markdown: `../2026-07-01-leadership-learning-handwritten-notes.md`

## Clean Markdown Text

This page focuses on storytelling, friendly speech, and presentation practice.

Key points:

- Know the target audience.
- Share information in a way the audience can receive.
- Practice the presentation.
- Use eye contact and gesture.
- Make the message personal and authentic.
- Build a memorable point rather than only presenting data.
- Storytelling is interactive: the listener should be able to picture the story.

## Interpretation

The page treats communication as leadership work. A message is not finished when it is accurate; it is finished when it can land with the audience.

## Personal Application

- Start with the audience before building slides or talking points.
- Pair data with a concrete story.
- Practice one clear point until it feels natural.
