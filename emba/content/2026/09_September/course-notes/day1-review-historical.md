## 一、核心主线：为什么实际课堂多出了一套公式？

在预习清单中，Berk & DeMarzo 教材只布置了时间价值、债券、股票估值和流动性管理，**跳过了 Chapter 11（风险收益）和 Chapter 12（CAPM）**。

但在课堂估值决策中，存在不可避免的因果链条：
* **分子**：北辰号未来赚多少钱？$\rightarrow$ **自由现金流 / 预期现金流**。
* **分母**：未来的钱打几折拿回今天？$\rightarrow$ **折现率（Discount Rate）**。

教授不能凭空假设折现率，必须推导“股东承担了多大风险、要求多少回报”，因此在课上现场推导了现代金融学的底层基石：

$$\boxed{\text{Risk（风浪大不大）} \rightarrow \text{Beta（多跟大盘晃）} \rightarrow \text{Required Return（股东要多少）} \rightarrow \text{Discount Rate（折现尺子）} \rightarrow \text{Present Value（现值）} \rightarrow \text{NPV（造不造船）}}$$

## 二、第一步：钱有时间价值与折现

假设北辰号承诺你：**1 年后给你 €110**。  
如果当前市场稳赚的无风险利率是 10%，那这 €110 今天只值：

$$PV = \frac{110}{1 + 10\%} = 100$$

* **Present Value (现值, PV)**：未来的钱折算到今天的价值。
* **Discount Rate (折现率, $r$)**：把未来的钱换算成今天的钱时所使用的“缩水率/尺子”。
* **管理含义**：未来承诺的一枚银币，不能和今天口袋里的一枚银币直接相加。它必须穿过时间和风险，折回今天。

## 三、第二步：利率与债券价格的跷跷板关系

债券（Bond）的收益是契约固定的（定期支付息票 Coupon，到期偿还本金 Face Value）。

假设商会有一张旧债券，每年固定给你 **€5**：
* 如果市场利率**突然下降**（新发的债券只能给 €3），那张每年还固定给 €5 的旧债券就变成了“香饽饽”，大家都去抢，因此**债券价格上涨**。
* 反过来，如果市场利率**突然上升**（市场上随便都能赚 €7），每年只给 €5 的旧债券就被嫌弃，必须降价才能卖掉，因此**债券价格下跌**。

$$\boxed{\text{Interest Rate } \downarrow \quad \Longrightarrow \quad \text{Bond Price } \uparrow}$$
$$\boxed{\text{Interest Rate } \uparrow \quad \Longrightarrow \quad \text{Bond Price } \downarrow}$$

* **核心结论**：债券价格与市场利率呈**反向变动**关系。

## 四、第三步：股票与项目的不确定性——预期现金流

债券的现金流是合同写死的，但**北辰号的航运生意（股票与项目）是不确定的**：
* 航运繁荣（好年，60% 概率）：赚 €150
* 航运平稳（平年，30% 概率）：赚 €120
* 爆发战争/萧条（差年，10% 概率）：赚 €50

不能单凭主观乐观认定“明年肯定拿 €120”，必须计算**预期现金流（Expected Cash Flow, $E(CF)$）**：

$$E(CF) = \sum (p_i \times CF_i)$$
$$E(CF) = 150 \times 60\% + 120 \times 30\% + 50 \times 10\% = 90 + 36 + 5 = 131$$

所以北辰号明年预期的真实进账是 **€131**。

## 五、第四步：课堂最大难点——折现率从哪来？

这算出来的 €131 是**“带有巨大风浪的 €131”**，不能直接用银行 3% 的无风险利率去折现。  
**股东冒了风险，要求的回报率必须更高。高出多少？由 CAPM 决定。**

### 5.1 两种风险：特有风险 vs 系统性风险

| 风险类别 | 学名 | 人话解释 | 北辰号案例 | 能否分散？ | 市场给补偿吗？ |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **特有风险** | Idiosyncratic Risk<br>(Unsystematic) | 公司自己家的风险 | 船长突然辞职、零件损坏、个别客户违约 | **能**（通过组合投资） | **不补偿**（因为自己能免费消除） |
| **系统性风险**| Systematic Risk<br>(Market Risk) | 整个大环境的风险 | 宏观经济衰退、利率飙升、全航道封锁、战争 | **不能**（所有船都受影响） | **补偿**（通过 Beta 索要 Risk Premium） |

### 5.2 雨伞与冰淇淋：协方差（Covariance）与分散化

* **天气炎热**：冰淇淋大卖，雨伞销量惨淡。
* **暴风雨天**：雨伞销量爆发，冰淇淋无人问津。

两家公司的收益呈现**负协方差（Negative Covariance）**。  
如果你同时投资雨伞公司和冰淇淋公司：
* 一个业务差的时候，另一个正好补偿；
* 整体资产组合的波动被抹平，这就是**分散化（Diversification）**；
* 投资人靠多买几只股票就能消除特有风险，所以**资本市场绝不会因为你公司自己管理不善、船长辞职而多给你一分钱的风险回报**。

### 5.3 Beta 的本质：跟着市场晃多少

市场只关心一件事：**当大风暴来临（整个市场波动）时，北辰号会跟着晃多大？**

$$\beta_i = \frac{Cov(r_i, r_m)}{Var(r_m)}$$

* **Variance（方差）**：整个市场自己晃得有多厉害。
* **Covariance（协方差）**：北辰号和大市场是不是同频一起晃。
* **Beta（贝塔值）**：敏感度倍数。
  * $\beta = 1.0$：大盘涨跌 10%，北辰号也涨跌 10%（中规中矩）。
  * $\beta = 1.5$：大盘涨 10%，北辰号暴涨 15%；大盘跌 10%，北辰号暴跌 15%（高弹性、高风险）。
  * $\beta = 0.5$：对大环境钝化，大盘大跌它只微跌（防御型）。

### 5.4 CAPM：算定股东要求的折现率

$$E(r_i) = r_f + \beta_i \times [E(r_m) - r_f]$$

* $r_f$（无风险利率）：存银行稳赚的底座，如 **3%**。
* $[E(r_m) - r_f]$（市场风险溢价, Market Risk Premium）：投整个股票大盘相对无风险利率平均要求多赚的补偿，如 **6%**。
* $\beta_i$：北辰号的市场敏感系数，如 **1.5**。

代入计算：
$$E(r) = 3\% + 1.5 \times 6\% = 3\% + 9\% = 12\%$$

这个 **12%** 就是投资北辰号股权时，股东要求的必要回报率（Cost of Equity），也是折现率！

### 闭环计算：北辰号到底值多少？

将第三步的预期现金流（€131）与第四步算出的折现率（12%）合体：

$$PV = \frac{E(CF)}{1 + E(r)} = \frac{131}{1 + 12\%} \approx 117 \text{ 欧元}$$

* **结论**：考虑了一年时间的等待、航运可能好可能坏的概率、以及北辰号跟着大盘晃动的系统性风险后，**未来预期的 €131，今天真实价值大约是 €117**。

## 六、第五步：借钱混搭——加权平均资本成本（WACC）

如果造北辰号不全是股东出钱，还向银行借了债：
* 股权出资占比 $\frac{E}{V}$，要求回报率 $r_e = 12\%$（由 CAPM 算出）；
* 债务出资占比 $\frac{D}{V}$，银行借款利息 $r_d = 5\%$；
* 因为利息在税前扣除具有**抵税盾牌（Interest Tax Shield）**，真实税后债务成本为 $r_d(1 - \tau_c)$。

$$WACC = \frac{E}{V} r_e + \frac{D}{V} r_d (1 - \tau_c)$$

此时评估整个北辰号项目的总价值时，折现率就要用 **WACC** 代替纯股权折现率。

## 七、第六步：下午延伸——既然能分散，为什么还要风险管理？（Stulz 理论）

下午 René Stulz (1996) 与 Nocco & Stulz (2006) 的论文直击核心矛盾：
> **“既然股东自己买 50 只股票（雨伞+冰淇淋）就能分散特有风险，为什么商会还要花真金白银买衍生品、设立备用航线做风险管理？”**

### 1. 答案：防止财务困境与猝死（Costs of Financial Distress）
* 股东资产多元化，北辰号倒闭了，股东在其他公司上赚的钱能弥补亏损；
* **但北辰号自己会死！** 航运市场出现极端断崖时，商会现金流断裂，银行抽贷违约，商会码头被查封，员工遣散——这种破产清算造成的永久性价值毁灭，是股东的分散化救不回来的。

### 2. 伊莱的对冲三原则（Hedging Rules）
1. **有货的盾才叫保护，没有货的盾就是赌博**：只对冲真实持有的货物敞口（Exposure），不为臆想出来的未来虚空对冲。
2. **核心风险自己担，非核心风险低成本转移**：
   * **Core Risk**（船型选择、航海技术、客户维系）：这是商会赚超额利润的来源，必须自己扛；
   * **Non-Core Risk**（外汇汇率暴跌、燃油价格暴涨、黑石海峡意外封锁）：商会没有预测优势，应该用 Forward、Option 或保险锁定。
3. **备用能力（“灯火号”）**：平时走南方航线哪怕微亏，也买下了在危机时刻迅速切换航线的能力。一条从未走过的路，不算退路。

## 八、第七步：全天公式一页纸极简速查表（Cheatsheet）

### 1. 资产估值与现金流模块

| 公式名称 | 数学表达式 | 商业通俗翻译 |
| :--- | :--- | :--- |
| **单笔现金现值** | $PV = \frac{FV}{(1+r)^t}$ | $t$ 年后的钱折算到今天值多少。 |
| **永续年金** | $PV = \frac{C}{r}$ | 每年固定拿 $C$，永远拿下去的总价值。 |
| **永续增长模型** | $PV = \frac{C_1}{r - g}$ | 每年现金按 $g$ 的速度增长时的总价值。 |
| **净现值 (NPV)** | $NPV = \sum \frac{CF_t}{(1+r)^t} - \text{Initial Outlay}$ | 创造的全部现值扣掉造船成本，大于0就造。 |
| **自由现金流 (FCF)** | $FCF = EBIT(1-\tau) + Depr - CapEx - \Delta NWC$ | 扣除再投资与压资后，真正能落袋为安的现金。 |

### 2. 折现率与资产定价模块

| 公式名称 | 数学表达式 | 商业通俗翻译 |
| :--- | :--- | :--- |
| **方差 (Variance)** | $Var(r_m) = \sigma_m^2$ | 整个市场自己上下起伏晃得有多剧烈。 |
| **协方差 (Covariance)**| $Cov(r_i, r_m)$ | 北辰号是否跟大盘同进同退、一起同向晃。 |
| **贝塔系数 (Beta)** | $\beta = \frac{Cov(r_i, r_m)}{Var(r_m)}$ | 北辰号相对于大盘的敏感放大倍数。 |
| **CAPM 股权回报率** | $r_e = r_f + \beta (r_m - r_f)$ | 无风险利息底座 + 系统性风险补偿。 |
| **加权资本成本 (WACC)**| $WACC = w_e r_e + w_d r_d (1-\tau)$ | 股权和债权综合起来的平均资金成本。 |

### 3. 流动性与活命周转模块

| 公式名称 | 数学表达式 | 商业通俗翻译 |
| :--- | :--- | :--- |
| **净营运资本 (NWC)** | $NWC = \text{Current Assets} - \text{Current Liabilities}$ | 压在日常周转里的流动垫片资金。 |
| **现金周转周期 (CCC)** | $CCC = DIO + DSO - DPO$ | 存货天数 + 应收天数 - 应付天数；钱悬空的天数。 |

## 九、与后续课程的连接（周五 Day 5 伏笔）

今天学的这套公式，在周五 **Roger Otten 教授的基金投资与绩效评价课**上会直接升级为 **Carhart 四因子模型**：

$$R_{it} - R_{ft} = \alpha_i + \beta_{i1}(R_{mt} - R_{ft}) + \beta_{i2} SMB_t + \beta_{i3} HML_t + \beta_{i4} MOM_t + \epsilon_{it}$$

* **今天的 $\beta$**：就是公式里的第一项市场 Beta（$\beta_{i1}$）。
* **周五的升级**：基金经理宣称自己赚到了额外收益（$\alpha_i$），但实证研究发现，把市场大盘（Beta）、公司规模（SMB）、价值倾向（HML）和动量效应（MOM）剔除后，大部分主动基金真实的超额收益 $\alpha$ 都是 0。
* **逻辑完全连通**：今天学透了 Beta 和系统性风险，周五的量化分析就是轻车熟路。
