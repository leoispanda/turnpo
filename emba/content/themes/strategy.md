## Current Synthesis

The first strategic theme is preparation as a strategic act. The EMBA is not only a course calendar; it is a two-year thinking system. June's documents point to three strategic responsibilities: protect thinking time, choose electives with a thesis, and bring real business questions into each module.

## Key Concepts

- Strategic thinking is different from fast execution.
- Protected thinking time is a leadership resource.
- Elective choice should serve a clear development thesis.
- A useful module should sharpen a real decision boundary at work.
- Strategy starts with a concrete use case, then tests assumptions.

## Running Questions

- What business or leadership question should each EMBA module help answer?
- Which assumptions would change my current strategy?
- Where should I compete, where should I not compete, and why?
- Which elective path best supports Turnpo, MapKAI, DishKAI, and my founder development?
